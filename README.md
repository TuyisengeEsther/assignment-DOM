# Explore Rwanda Website

## Project Description

Explore Rwanda is a responsive tourism and activity planner website built using HTML, Tailwind CSS, and JavaScript DOM manipulation. The project allows users to explore activities, add items to a planner, search activities dynamically, and interact with different DOM features.

---

## Features

- Responsive Navigation Bar
- Dropdown Menu
- Dark Mode Toggle
- Mobile Hamburger Menu
- Dynamic Hero Text Change
- Personalized Welcome Message
- Activity Cards
- Dynamic Activity Planner
- Search Functionality
- Responsive Gallery Section
- Contact Form
- Footer Section

---

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript DOM Manipulation

### Navigation
- Active navigation highlighting
- Dropdown toggle
- Mobile menu toggle

### DOM Manipulation
- Change hero section text dynamically
- Display personalized welcome message
- Add activities dynamically
- Remove activities on click
- Search activities in real-time

### Theme
- Dark and Light mode switching
